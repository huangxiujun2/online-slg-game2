# 邊境紀元

使用 Vue 3、Vite 與 Socket.IO 製作的即時多人 2.5D 策略遊戲原型。建立房間後分享五位數代碼，另一位玩家即可加入同一場戰局。

## 開始遊戲

```sh
npm install
npm run dev
```

開啟 Vite 顯示的網址（預設 `http://localhost:5173`）。多人遊玩時，將這個前端網址分享給朋友；Vite 會將 Socket.IO 連線轉送到同一主機上的遊戲伺服器。

若要分開啟動前端與伺服器：

```sh
npm run server
npx vite --host 0.0.0.0
```

## 操作方式

- 輸入名稱並建立房間，將房間代碼分享給朋友。
- 點選自己的村民或劍士，再點擊地圖移動；按 `A` 可選取全部部隊，按 `Esc` 取消選取。
- 村民會生產食物，城鎮會持續生產木材與黃金；訓練劍士並帶往敵方城堡即可發動攻擊。
- 摧毀對方城堡（耐久降至 0）即可獲勝。

目前房間狀態存放於伺服器記憶體；重新啟動伺服器會清除進行中的戰局。
